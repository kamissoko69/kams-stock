# KAMS Stock Pro
SaaS de gestion d'inventaire, ventes, marges et mouvements.
Stack: Node.js/Express + PostgreSQL + HTML/CSS/JS + Nginx + Docker.
Lancement: `docker compose up -d --build`
URL: `http://localhost:5173`
Démo: `admin@kamsstock.com` / `Kams@1234`
IMPORTANT: changer JWT_SECRET, DB password et compte admin avant production.
